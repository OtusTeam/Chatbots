# Урок 20 — RAG-бот с векторным поиском (Qdrant)

Пошаговая инструкция для запуска бота: векторная база по документам из папки `docs`, поиск по смыслу, ответы с указанием источника.

## 1. Ставим зависимости

Из корня урока 20:

```bash
pip install -r requirements.txt
```

Нужны: `openai`, `python-dotenv`, `qdrant-client`, `tqdm`, `aiogram`, `gigachat` (и их зависимости).

## 2. Создаём .env

Скопируйте шаблон и заполните переменные:

```bash
cp .env.example .env
```

Обязательно задайте:

- **TELEGRAM_BOT_TOKEN** — токен бота из [@BotFather](https://t.me/BotFather).
- **GIGACHAT_CREDENTIALS** — ключ для LLM (сборка ответа по контексту).
- **BASE_URL**, **EMBEDDING_MODEL** — URL и имя модели API эмбеддингов (например локальный сервер на `http://localhost:1234/v1`).

Остальные переменные можно оставить по умолчанию из `.env.example` (чанкование, Qdrant, порог score и т.д.).

## 3. Добавляем документы

Положите текстовые файлы (например, `.txt`) в папку **`docs/`** в корне урока. Бот будет искать ответы только по этим документам. При необходимости создайте папку:

```bash
mkdir -p docs
# затем скопируйте или создайте в docs нужные .txt файлы
```

## 4. Индексируем документы

Поднимите Qdrant (если ещё не запущен):

```bash
docker-compose -f docker-compose.qdrant.yml up -d
```

Запустите индексацию из корня урока 20:

```bash
python ingest.py
```

Скрипт прочитает файлы из `docs/`, разобьёт на чанки, получит эмбеддинги и запишет векторы в Qdrant. После успешного завершения можно запускать бота.

## 5. Запускаем бота

Из корня урока 20:

```bash
python main.py
```

Бот будет отвечать на сообщения: ищет релевантные фрагменты в векторной базе, собирает ответ через LLM и при необходимости указывает источник (файл). Если релевантного контекста нет или ответ «Не знаю», источник не выводится.

---

**Кратко:** зависимости → `.env` → файлы в `docs/` → `docker-compose -f docker-compose.qdrant.yml up -d` → `python ingest.py` → `python main.py`.
