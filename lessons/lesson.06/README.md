## Занятие 6: FSM в aiogram — сценарий `/prof` (профессия → уровень)

### 1) Что такое FSM в проекте

* **FSM** = бот “помнит шаг диалога” для каждого пользователя.
* Нужен для анкет/опросов, чтобы “эхо на любой текст” не ломало сценарий.
* Сценарий урока: `/prof` → **профессия** → **уровень** → итог → **очистка состояния**.

---

### 2) Где что лежит в проекте

* Хендлер сценария: `lesson/app/handlers/career_choice.py`
* Клавиатуры/билдер: `lesson/app/keyboards/builders.py`
* Подключение storage + порядок роутеров: `lesson/main.py`

---

### 3) Ключевые сущности aiogram (минимум)

* `Router` — изолируем сценарий в отдельном модуле.
* `StatesGroup`, `State` — описываем шаги.
* `FSMContext` — доступ к состоянию и данным пользователя.
* Storage (на уроке): `MemoryStorage` — живёт пока процесс бота запущен.

---

### 4) Состояния сценария

* `CareerChoice.job` — шаг выбора профессии.
* `CareerChoice.grade` — шаг выбора уровня.

---

### 5) Порядок роутеров (важно!)

* FSM-роутер **подключаем выше** “эхо на любой текст”, иначе эхо перехватит сообщения.
* Практическое правило: **сценарии (FSM) → меню/команды → эхо**.

---

### 6) Клавиатуры (ReplyKeyboard)

* Используем **Reply-клавиатуру** для выбора из вариантов.
* Делаем “билдер”:

  * вход: `list[str]`
  * выход: `ReplyKeyboardMarkup`
* Варианты урока:

  * профессии: список строк
  * уровни: список строк

---

### 7) Валидация ввода на шаге

* Проверяем: `message.text` **входит ли** в список вариантов текущего шага.
* Если нет — повторяем вопрос и показываем клавиатуру снова.
* Если да — сохраняем и двигаемся дальше.

---

### 8) Хранение данных между шагами

* `await state.update_data(profession=..., grade=...)` — кладём промежуточные значения.
* `data = await state.get_data()` — достаём всё в конце.

---

### 9) Переходы между шагами

* `await state.set_state(CareerChoice.job)` — перейти на шаг профессии.
* `await state.set_state(CareerChoice.grade)` — перейти на шаг уровня.

---

### 10) Завершение сценария

* После выбора уровня:

  * достаём `profession` из `get_data()`
  * формируем итог: “Профессия …, уровень …”
* **Сбрасываем состояние**:
  * `await state.clear()`
